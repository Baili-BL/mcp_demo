SQL 占位符使用说明

占位符让同一份 SQL 数据集按调用时传入的值或当前访问用户的身份动态过滤。写法与 Quick BI 一致： 在 SQL 里放占位符，在「占位符管理」里设置变量类型和默认值；数据集发布成 MCP 工具后，占位符会自动变成工具的入参。

快速上手 六类占位符 值 表达式 条件 加速 标签 系统 配置项 校验规则 与 MCP 工具 常见问题

快速上手

  1. 进入「数据准备 › 数据集」，点击 SQL 数据集，选择数据源。
  2. 在编辑器里写 SELECT，并在需要动态的地方写占位符，例如 WHERE region IN ('$val{region_ph}')。
  3. 点击工具栏的 占位符管理，右侧抽屉会列出系统自动识别到的占位符。按钮上的数字是占位符个数，变红表示有配置错误。
  4. 为每个占位符选择变量类型，填写查询默认值并选择生效范围（仅数据集 / 全局生效），点击「确定」。
  5. 点击 运行。「运行结果」展示预览数据，「实际执行 SQL」展示占位符替换后的语句。用到标签 / 系统占位符时，可在右上角切换预览身份。
  6. 点击 确认编辑 保存。占位符配置随数据集一起保存，再次编辑时会回显。
手动新建：在抽屉里点击「新建占位符」，选择类型、填写变量名（表达式 / 条件 / 加速还要选物理字段），添加后点该行的「插入」，占位符会写到 SQL 编辑器的光标位置。

六类占位符一览

类型写法用途
值'$val{name}'传入一个值或一组值；日期区间用 .get(0) / .get(1) 取起止
表达式$expr{字段:name}传入完整筛选条件（字段 + 运算符 + 值），调用方可自由选择筛选方式
条件$condition{一级字段,二级字段:name}按层级传入一组值，字段最多 10 个
加速$accel{字段:name}抽取加速时动态替换时间窗口；每个数据集仅 1 个，仅数据集层生效
标签'$tag{标签名}'取当前访问用户的标签值，做按人过滤
系统'$system{accountName}'取当前访问用户的账号信息

旧写法 ${name} 仍可使用，按值占位符处理。

值占位符

值最常用。文本、日期要用英文单引号包住，数值不加引号；多选文本放在 IN ('…') 里，系统会把多个值展开成 'a', 'b'。

SELECT * FROM base_from_ths_data
WHERE region IN ('$val{region_ph}')   -- 文本 多选
  AND variety = '$val{variety_ph}'  -- 文本 单选
  AND qty > $val{min_qty}             -- 数值
  AND trade_date >= '$val{rg.get(0)}' -- 区间起始
  AND trade_date <= '$val{rg.get(1)}' -- 区间结束
SQL 写法
SELECT * FROM base_from_ths_data
WHERE region IN ('华东', '华北')
  AND variety = 'CU'
  AND qty > 100
  AND trade_date >= '2026-09-01'
  AND trade_date <= '2026-09-30'
默认值：region_ph = 华东,华北；variety_ph = CU；min_qty = 100；rg = 2026-09-01~2026-09-30
没有传值时：值占位符所在的整个条件会被替换成 1=1，等于不过滤；「实际执行 SQL」上方会提示是哪个占位符被跳过。
区间默认值：用了 .get(0) / .get(1) 的占位符，默认值写成 起始~结束。
类型自动判断：不带引号的 $val 会被识别为「数值」，带 .get 的识别为「日期-年月日」，可在抽屉里改。

表达式占位符

表达式把整个筛选条件交给调用方：等于、大于、介于都由传入的表达式决定。冒号前是物理字段名，冒号后是占位符名。

SELECT trade_date, variety, price
FROM base_from_ths_data
WHERE $expr{trade_date:trade_date}
  AND $expr{variety:variety_ph}
SQL 写法
SELECT trade_date, variety, price
FROM base_from_ths_data
WHERE trade_date >= '2026-01-01'
  AND variety IN ('CU', 'AL')
trade_date 默认值写完整表达式；variety_ph 只写值 CU,AL，系统自动补成 IN

默认值可以写完整表达式（如 area = '东北'），也可以只写值：一个值生成 字段 = '值'，多个值（逗号分隔）生成 字段 IN (…)。不传值时整段替换为 1=1。

条件占位符

条件用于层级取值，例如「板块 › 品种」。字段按层级顺序写，最多 10 个，顺序需与调用方传入的层级一致。

SELECT * FROM base_from_ths_data
WHERE $condition{sector,variety:sector_tree}

预览运行时按第一级字段生成条件，例如默认值 有色,黑色 生成 sector IN ('有色', '黑色')；不传值时为 1=1。

加速占位符

加速放在 WHERE 中，用于大表的抽取加速：编辑和预览阶段用默认值限定一个较小的时间窗口，避免 SQL 运行超时；正式抽取时由引擎按配置动态替换时间范围。

SELECT * FROM edb_series_data
WHERE $accel{data_time:data_time_acc}
-- 默认值（必须是完整表达式）：data_time >= '2026-01-01'
  • 每个数据集只能有 1 个加速占位符。
  • 默认值生效范围固定为「仅数据集」，不能改；默认值必须是完整过滤表达式，不能只写一个日期。
  • 加速占位符不会出现在发布的 MCP 工具入参里。

标签占位符

标签在运行时读取当前访问用户的标签，适合「每个人只看自己团队的数据」。可用标签取自「用户与接入」中的用户信息：

标签取值来源示例（陈可）
团队用户的团队 / 公司数智中心
角色用户的角色管理员
用户组用户加入的所有用户组（多个值）数智中心
身份内部员工 / 外部客户内部员工
 
SELECT * FROM crm_account
WHERE team = '$tag{团队}'
  AND owner_group IN ('$tag{用户组}')
SQL 写法
SELECT * FROM crm_account
WHERE team = '数智中心'
  AND owner_group IN ('数智中心')
以「陈可」身份运行

标签占位符不需要默认值。在 SQL 编辑页运行时，结果区右上角会出现「预览身份」，切换用户即可看到不同人的执行结果。

系统占位符

系统取当前访问用户的账号信息，支持 4 个变量：

写法含义示例（陈可）
$system{accountName}用户名（登录账号，优先邮箱，其次手机号）chenke@example.com
$system{userNick}用户昵称（组织内姓名）陈可
$system{userId}平台内用户 IDu-admin
$system{accountId}三方系统用户 ID（企业微信 userid）chenke
 
SELECT * FROM crm_account WHERE owner = '$system{userNick}'

配置项

配置项说明
变量名占位符名称，可直接在抽屉里修改；修改后 SQL 中的引用会一起替换。系统占位符的变量名不可改。
类型值 / 表达式 / 条件 / 加速 / 标签 / 系统，由写法决定，识别后不可修改。
变量类型文本、数值、日期-年、日期-年季、日期-年月、日期-年周、日期-年月日、日期-年月日时分秒。标签和系统占位符运行时取当前用户，无需设置。
查询默认值最多 150 个字符。表达式 / 加速占位符的默认值填完整表达式，如 report_date < '2025-04-01'。
生效范围仅数据集：只在 SQL 编辑页运行时使用。全局生效：发布的 MCP 工具等下游也使用，调用方不传值时取该默认值。
引用显示该占位符在 SQL 中出现的次数，以及是否用在 SELECT、是否是区间写法；手动新建但还没插入的显示「未引用」。
操作「插入」写到 SQL 光标处；删除表达式 / 条件 / 加速占位符时，SQL 中对应片段会替换为 1=1。

校验规则

以下 ✕ 项会阻止「确定」和「确认编辑」，! 项只提示不阻止。

✕用在 SELECT 语句中的值 / 表达式 / 条件占位符，必须设置全局生效的默认值。
✕每个数据集仅支持 1 个加速占位符；加速占位符的默认值必须是完整表达式。
✕默认值不超过 150 个字符；数值类型的默认值必须是数字。
✕条件占位符字段不超过 10 个；系统占位符只能用 accountName / userNick / userId / accountId。
!值占位符没有默认值：运行时所在条件按 1=1 处理。
!日期默认值与所选变量类型格式不符；区间占位符默认值没有写成「起始~结束」。
!标签名不在用户标签中，运行时取值为空；手动新建的占位符尚未在 SQL 中引用。

与 MCP 工具的关系

带占位符的 SQL 数据集发布成 MCP 工具后：

类型在工具中的表现
值变成工具入参。数值为 number，区间为长度 2 的数组 [起始, 结束]，其余为 string；全局生效的默认值写入入参 default。
表达式变成 string 入参，传完整条件；不传则不过滤。
条件变成字符串数组入参，按层级传值；不传则不过滤。
标签 系统不暴露给调用方，由平台根据透传的用户身份自动填入，调用方无法伪造。需要所在服务在「MCP 中心」开启「透传用户身份」。
加速只在数据集层生效，不出现在工具入参中。
建议：按人隔离的数据优先用标签 / 系统占位符，或「数据权限」里的行权限，不要让调用方通过值占位符自己传团队、用户名。

常见问题

为什么文本占位符要加单引号？

系统只替换 $val{…} 本身，引号由 SQL 提供。写成 '$val{name}' 才能得到 '华东'；多选时得到 '华东', '华北'，所以要放在 IN (…) 里。

删除了占位符，为什么它又出现了？

列表是根据 SQL 自动识别的。值 / 标签 / 系统占位符删除后 SQL 不会自动改写，需要同时在 SQL 里删掉对应写法，否则下次识别会重新出现。

运行结果和「实际执行 SQL」不一致？

当前控制台的运行结果是按数据源抽样的预览数据，「实际执行 SQL」才是替换后会下发到数据库的语句，以后者为准核对占位符是否正确。

「仅数据集」和「全局生效」怎么选？

只为了在编辑页能跑通预览，选「仅数据集」；希望工具调用方不传值时也有兜底，选「全局生效」。用在 SELECT 里的占位符必须选「全局生效」。
