MCP 服务

mkt / fund / res / anl / dsx tools/list、tools/call，一工具一 DSN
校验 Key，取出 user_id 未绑工具集 → AUTH_FAIL；list 只回集内
按调用人编译 Grant 指标工具打 METRIC；数据集套行/列
数据面
schema · 占位符 SQL 禁止跨源 JOIN
METRIC / CRM / DW / Oracle / HTTP 只读；跨平台由 Agent 连续调用
会话身份 SET_IDENTITY / 会话变量带用户与组
中间视图 · 行 WHERE · 列掩码 白名单绕过；未匹配看 row_other / col_other
交叉格里「服务与工具 × 数据面」只能是一工具一 DSN。一个服务可以声明多个上游，但不能在一个 tool 里隐式跨库 JOIN。
