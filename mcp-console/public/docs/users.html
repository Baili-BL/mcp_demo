用户管理与注册

账号按内部员工与外部客户分开。管理员邀请时给出注册链接，对方用手机号 + 登录邮箱完成注册，而不是管理员代填联系方式。

两类账号

内部员工外部客户
对象分公司同事（数智中心、投研组等）产业客户、合作方
开通邀请链接，或内部自助申请（需审批）只能持邀请链接注册
登录手机号或企业邮箱手机号或登录邮箱
密钥按角色签发，可较高配额默认 90 天、低配额

邀请：给链接，不代填

  1. 管理员选择身份：内部员工 / 外部客户，填写团队或客户公司，可选填受邀人姓名。
  2. 生成链接 #register?t=inv-…，复制发给对方，7 天有效。
  3. 对方打开链接，填写姓名、手机号、登录邮箱。提交后状态为「正常」。
  4. 管理员再在「接入与密钥」把 Key 挂到该账号。
原则：先有人，再有 Key。邀请只证明「允许谁来注册」，手机与登录邮箱必须由本人填写。

角色

角色适用能做什么
管理员 / 开发 / 研究员内部员工管理、登记工具或使用已授权工具集
客户外部客户仅自己的配置与已授权工具集，看不到别人的 Key

状态机

待注册（链接未用）→ 正常。内部自助申请为 待审批 → 正常。均可 停用（名下 Key 全部失效）。
