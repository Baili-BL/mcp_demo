用户管理与注册

账号按内部员工与外部客户分开。内部员工从企业微信通讯录选择开通，手机号与企业邮箱由企微 API 返回；外部客户持邀请链接，用姓名 + 手机号自己注册，登录邮箱选填。

两类账号

内部员工外部客户
对象分公司同事（数智中心、投研组等）产业客户、合作方
开通企业微信通讯录选人，当场开通为「正常」只能持邀请链接注册
身份来源企微 userid / 部门 / 手机 / 企业邮箱（邮箱可空）必填姓名与手机号，登录邮箱选填
密钥按角色签发，可较高配额默认 90 天、低配额

内部员工：企业微信选人

  1. 管理员打开「开通用户」，选择「内部员工」，指定预置角色，并可下拉勾选内部团队筛选通讯录。
  2. 控制台调用企业微信通讯录 API（按部门 addressbook 拉人），展示姓名、部门、手机、企业邮箱。
  3. 勾选尚未开通的同事。已开通行不可选；「待注册 / 待审批」选中后直接变为「正常」。
  4. 提交后账号立即可用，再到「接入与密钥」把 Key 挂到该账号。
原则：内部身份以企业微信为准，不发邀请链接、不手工代填手机号。外部客户不在通讯录，仍走邀请链接。

外部客户：给链接，不代填

  1. 管理员选择「外部客户」，填写客户公司，可选填受邀人姓名。
  2. 生成链接 #register?t=inv-…，复制发给对方，7 天有效。
  3. 对方打开链接，填写姓名、手机号；登录邮箱选填。提交后状态为「正常」。
  4. 管理员再在「接入与密钥」把 Key 挂到该账号。

角色

角色适用能做什么
管理员 / 开发 / 研究员内部员工管理、登记工具或使用已授权工具集
客户外部客户仅自己的配置与已授权工具集，看不到别人的 Key

状态机

内部员工：企微选人后即为 正常（历史「待注册 / 待审批」可在通讯录中确认开通）。外部客户：待注册（链接未用）→ 正常。均可 停用（名下 Key 全部失效）。
