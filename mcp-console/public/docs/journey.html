Product Design · 旅程

用户旅程

按 S 形走完整条流程：管理员先配源、集、权限和服务，折返去建工具、工具集并开通发 Key，再把配置交给用户调用。

总览

第一行从左到右，右侧折返；第二行从右到左；左侧再向右进入用户调用。箭头方向即行走方向。

管理员配置
1登记数据源DSN · 只读 · 同步 schema
2创建数据集表 / 模型 / SQL
3配置权限行过滤 · 列掩码 · 协作者
4创建服务端点 · 勾数据源 · 透传身份
管理员开通
8签发密钥归属用户 + 绑定工具集
7开通用户企微选人 / 导入 · 入组
6创建工具集勾选工具，才能被 Key 绑
5创建工具探测 / 手工 / 发布数据集
用户调用
9粘贴配置url + Bearer，重启客户端
10提问调用list 只见工具集内工具
11受控结果按该用户套 Grant
12调用监控日志回写 · 告警 · 关系树
不要颠倒：没有已登记数据源就建不了服务；没有工具集，Key 绑不到任何工具；没有入组，行/列策略可能打不中。
