工程开发流程图

开发工程师从接到数据需求，到 MCP 服务可被密钥调用的路径。 先实现、再注册、最后才发 Key。跨库必须拆工具，禁止在一个 SQL 里打两套库。

总览

四段不可颠倒：摸清上游 → 写工具并自测 → 在管理台登记服务与工具 → 挂联调密钥并打开鉴权。

三个必须拦住的分叉

  1. 跨库：CRM 与数仓不在同一实例时，拆 search_crm_* 与 query_warehouse，由 Agent 连续调用。
  2. 目录不一致：tools/list 对不上就保持待发布，不要靠手工目录骗过客户端。
  3. 生产鉴权：MCP_AUTH_REQUIRED=0 只允许本机。预发和生产必须校验 Key、配额与到期。
