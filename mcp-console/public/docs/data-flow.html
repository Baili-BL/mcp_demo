Product Design · 数据流

数据流

配置面写 Grant 与工具目录；运行面用 Key 取出调用人，再决定能不能看见行和列。 两面必须读同一份权限定义。

总览

先在管理台把源、集、权限和工具写好；调用时从 Key 取用户，再按工具类型打库。数据集路径必须用调用人现场编译 Grant，禁止用「无调用人」时的 SQL 当最终 WHERE。
