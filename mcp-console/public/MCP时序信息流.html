创建顺序（不要颠倒）

  • 先登记数据源，再建数据集，再配行/列权限
  • 再创建服务（勾已有数据源）→ 创建工具（探测 / 手工 / 发布数据集）
  • 再创建工具集并勾选工具；没有工具集的服务对用户不可见
  • 最后开通用户、签发绑定工具集的 Key

两套权限

  • 工具集权限：Key 绑哪些工具，决定 tools/list 能看见什么
  • 数据权限：Grant 按用户/组滤行、掩列
  • 创建工具：探测上游，或「数据集 → 发布工具」挂 dsx
  • 既有工具读数据集：申请读取 + 中间视图 + 透传身份

用户侧流程

  • 内部企微选人；外部导入注册。入组后行/列策略才可能命中
  • 拿到 url + Bearer Key，写入客户端并重启
  • 提问后只调工具集内工具，结果已套该用户 Grant
  • 关系树从用户 / 服务 / 数据集三边核对是否受控
