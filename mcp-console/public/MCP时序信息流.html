鉴权与安全

  • Bearer Key 校验 base_from_mcp_api_key（enabled + expire_time），结果缓存 60s
  • 握手（initialize）放行；tools/list 与 tools/call 强制鉴权。失败分流：缺 Key / 已停用 / 已过期（AUTH_FAIL）
  • 用量限制（日配额 / QPS）与到期时间彼此独立：超限返回 429，过期直接拒绝鉴权
  • 客户端统一写 type: http（SSE 则为 sse）+ Bearer API Key。stdio 的 command/args/env 本服务不用
  • 密钥仅创建时完整展示；泄露后管理台一键吊销，临期可续期 90 天

数据源路由（source 参数）

  • 1 同花顺 → base_from_ths_*（3660 指标 / 440 万点）
  • 9 SMM → base_from_smm_*（1835 / 118 万）
  • 11 上海钢联(化工) → base_from_mysteel_chemical_*（2541 / 290 万）
  • 34 手工录入；EDB 双路径：派生读 edb_series_data，基础指标自动回源

可观测与运维

  • 调用日志字段与线上一致：key_name / tool_name / args / 耗时 / 行数 / 成功标识
  • 管理台「调用监控」：24h 趋势、P50/P95/P99、错误码分布、实时调用流
  • get_source_freshness 巡检逾期指标（end_date 超阈值，默认 10 天）
  • 服务健康探活 GET {endpoint}/health · 10s，连续失败自动切备
